# 二輪ローバー ミニプロジェクト

サークル活動の一環として取り組む、遠隔操作で走行する二輪ローバーの開発プロジェクト。
本リポジトリはソフト・エレキ・ハードの3班のうち **ソフト班** の担当範囲を扱う。

##  最終ゴール

遠隔通信で操作する **二輪ローバー** の開発

##  競技ルール

> 100秒で1.5m間隔に置かれたコーンの間を、箱を載せてジグザグに進む

### 得点計算式

```
得点 = x + y − z + α
```

| 変数 | 内容 |
|---|---|
| x | コーンの間を通った回数 |
| y | 運べた箱の数 |
| z | 落とした箱の数 |
| α | エクストラサクセスの評価点（加点要素） |

### 制限事項

- 機体の総重量は **1kg未満**

##  マイコン（ESP32）について

本プロジェクトでは ESP32 DevKit V1互換38pinボード（FT232 / Micro USB搭載）を使用する。
公式データシートが存在しない互換基板のため、Espressif公式資料をもとに整理した日本語クイックリファレンスをリポジトリに同梱している（`docs/ESP32_チーム2用.pdf`）。

**特に注意すべきピン**

- GPIO 6〜11：内蔵Flash用のため**使用禁止**（接続すると起動不能・破損の恐れ）
- GPIO 0 / 2 / 5 / 12 / 15：起動ストラップピン。外部回路によって起動不良を起こしうるため要注意
- GPIO 34〜39：**入力専用**（PWM出力やモータ制御には使えない）
- GPIOは3.3V systemであり **5V非対応**。5V系の周辺機器と接続する場合はレベル変換が必要

##  検討事項・注意点

1. **モータドライバは1回路（1モータ分）**
   秋月のTB67H450モジュールは「ドライバー回路数：1」であり、1個で駆動できるのはモータ1個分。二輪駆動（左右独立制御）には**モジュールが2個必要**、もしくは2回路搭載のドライバ（例：TB6612など）に変更する必要がある。
2. **モータの起動電流とドライバの電流容量**
   使用予定のDCモータは12V/620RPMで定格出力18.65W程度（＝定格電流1.5A程度）だが、起動時・拘束時の突入電流はブラシ付きギアモータでは定格の数倍に達することが多い。TB67H450の出力電流上限は3Aのため、負荷条件によっては上限に達する可能性がある。実機での電流実測を推奨。
3. **電源系統の電圧マッチングは概ね問題なし**
   LiPo（3S、公称11.1V、満充電時約12.6V）は、DCDCコンバータの入力範囲（6.5〜32V）およびモータドライバの電源範囲（4.5〜44V）の両方に収まっているので問題なし。
4. **ESP32のGPIOロジックは3.3V**
   モータドライバのロジック入力電圧・PWM入力の許容範囲を確認し、必要であればレベルシフトやプルアップ抵抗の追加を検討。
5. **1kg未満の重量制約**
   バッテリー・モータ2個・ドライバ・ESP32・シャーシ・荷台機構をすべて合わせて1kg未満に収める必要がある。モータとバッテリーが重量の大部分を占めるため事前に計測しておきたい。
